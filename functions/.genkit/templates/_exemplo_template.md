# Política de Privacidade

## 1. Introdução

A [EMPRESA] está comprometida com a proteção dos dados pessoais de seus clientes, colaboradores e parceiros, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

## 2. Dados Pessoais Coletados

| Categoria | Exemplos | Finalidade |
| --- | --- | --- |
| Dados de identificação | Nome, CPF, RG | Identificação do titular |
| Dados de contato | E-mail, telefone | Comunicação |
| Dados financeiros | Cartão de crédito | Processamento de pagamentos |
| Dados de navegação | IP, cookies | Melhoria da experiência |

## 3. Bases Legais

- **Consentimento** (Art. 7º, I): Quando o titular autoriza o tratamento.
- **Execução de contrato** (Art. 7º, V): Para cumprimento de obrigações contratuais.
- **Legítimo interesse** (Art. 7º, IX): Para fins legítimos do controlador.

## 4. Direitos do Titular

1. Confirmação da existência de tratamento
2. Acesso aos dados
3. Correção de dados incompletos
4. Anonimização, bloqueio ou eliminação
5. Portabilidade dos dados
6. Eliminação dos dados tratados com consentimento
7. Informação sobre compartilhamento
8. Revogação do consentimento

## 5. Segurança dos Dados

A [EMPRESA] adota medidas técnicas e administrativas para proteger os dados pessoais, incluindo criptografia, controle de acesso e auditoria regular.
